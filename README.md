# Hushwater

Hushwater is a cozy online survival hangout built for a small group of friends.

This repository contains the Windows desktop build, installer workflow, and update system.

## Player experience

- Install Hushwater once with the Windows setup executable.
- Host or join using Hushwater's room-code multiplayer.
- Keep local saves and profile data between normal updates.
- New releases can be downloaded from inside the installed game.

## Development

The Windows app uses Electron and electron-builder. GitHub Actions builds and publishes Windows releases.

Hushwater is currently private-development software even though this repository is public for updater/release convenience.
